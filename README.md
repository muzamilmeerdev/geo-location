# 📍 GeoRegister

A simple Flask location registration demo for learning browser geolocation, maps, and reverse geocoding.

## Features

- 📍 Get user's location with permission
- 🔎 Search locations
- 🗺️ Leaflet + OpenStreetMap map
- 📌 Select location using marker
- 🌐 Reverse geocoding
- 📝 Registration form

## Run

```bash
pip install -r requirements.txt
python app.py
